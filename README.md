# unionproduct

Комплексный компонент который предназначен для ссылочной наполняемости сайта, и сео продвижения.
Компопнент объединяет товары на сайте по определенным группам. Например По производителю и по алфавиту. 
 - https://www.tvoyaapteka.ru/unionproduct/
 - https://www.tvoyaapteka.ru/unionmanufact/
 
Создаются страницы с списком товаров и ссылками на них
Был разработан с нуля комплексный компонент который объдиняет товары, формирует ссылки.
После перехода по ссылке открывается полноценная страница каталога с сгруппированными товарами 

Есть возможность объединять товары по любым свойствам каталога и формировать ссылочные страницы

unionproduct.labels - не применяется
